# Внутри — карточки схема-терапии

Статический сервис для знакомства с карточками и подготовки к встрече с психологом. HTML, CSS и JavaScript, без сборки, API, аккаунтов, аналитики и внешних зависимостей.

## Возможности

- Каталог с четырьмя типами, подгруппами, поиском и фильтром по личным отметкам.
- Просмотр восстановленной иллюстрации, полное текстовое описание, пояснения с источниками и вопрос для наблюдения. Фотографии оборотов в интерфейсе не показываются.
- Узнавание, отметки «Хочу обсудить» и «Мой ресурс», собственное имя режима и заметки.
- Профиль, тема встречи и связь карточек в одной ситуации.
- localStorage, экспорт/импорт JSON, печать в PDF, удаление профиля с подтверждением.
- Проверка версии/содержимого импортируемого файла; повреждённые данные не перезаписываются автоматически. Конфликт между вкладками переводит текущую вкладку в режим без записи, с явным предупреждением.

Профиль не является стандартизированным тестом или диагнозом. Сервис не устанавливает причин, не рассчитывает выраженность схем и не предлагает самостоятельную работу с травматическими воспоминаниями.

## Данные

122 предоставленные фотографии: 5 снимков инструкции и 117 снимков 75 разных карточек. Коллекция полная и совпадает с инструкцией: 10 потребностей, 18 ранних схем, 14 позитивных схем, 33 режима. Полные тексты 42 описаний перенесены в `site/card-text.js`. Режимы представлены одним иллюстрированным вариантом; оборот в оригинальной колоде содержит другой гендерный вариант.

`site/data.js` связывает стороны, названия, краткие пересказы и источники. Пояснения режимов основаны на литературе и явно отделены от текста оригинальной колоды. Вопросы — редакционная адаптация для самонаблюдения.

## Запуск и проверка

```sh
npm start
npm test
```

Локальный адрес: http://127.0.0.1:4173. Сборка не требуется. GitHub Actions проверяет модель профиля и каталог, затем публикует только папку `site` на GitHub Pages при push в `main`.

## Приватность

Заметки находятся только в localStorage браузера под ключом `vnutri.profile.v1`. JSON/PDF формируется по запросу пользователя. `connect-src 'none'` блокирует сетевые запросы из JS; все ресурсы локальные для сайта. Сам хостинг получает обычные HTTP-запросы файлов. Данные не зашифрованы; очистка хранилища браузера может их удалить. Профили с localhost и GitHub Pages не синхронизируются, нужен экспорт/импорт.

## Подготовка фотографий

Все 75 лицевых иллюстраций приведены к JPEG 900×1200. После выравнивания перспективы встроенный Imagegen удалил тени телефона и блики, выровнял освещение и бумажный фон. Пользователь одобрил образец такой обработки; это генеративная реставрация с возможными небольшими отличиями деталей от печатного оригинала. Содержание, композиция, подписи и авторские пометки сохранялись максимально близко к источнику. `site/originals` хранит веб-копии исходных снимков; пять фото инструкции не кадрировались. Исходники, координаты, журналы обработки и полные промпты находятся в локальной исключённой из репозитория папке `research`.
