# Внутри — карточки схема-терапии

[Открыть сервис](https://seregqa-m.github.io/schema-cards/)

75 карточек для самонаблюдения и подготовки к встрече с психологом: потребности, ранние и позитивные схемы, режимы. Сервис не является диагностическим тестом.

## Возможности

- Каталог с поиском, фильтрами, иллюстрациями и описаниями.
- Выбор карточек по картинкам, личные отметки и заметки.
- Три упражнения: дневник ситуации, три шага Здорового Взрослого и карточка поддержки.
- Выгрузка выбранных карточек, описаний и записей в один PDF для психолога.
- Резервная копия и восстановление записей через JSON.

Работает на телефоне и компьютере. Источники пояснений доступны в карточках и разделе «Как работать»; основания упражнений — в [EXERCISES.md](EXERCISES.md).

## Приватность

Ответы, отметки и заметки не отправляются на сервер. Они сохраняются в `localStorage` вашего браузера. PDF и JSON создаются на устройстве. Аккаунтов и аналитики нет.

Это можно проверить в коде: [сохранение записей](site/app.js), [создание PDF](site/report.js), [сетевые ограничения](site/index.html). GitHub Pages получает обычные запросы файлов сайта и картинок, но не содержимое записей.

Очистка данных браузера может удалить записи. Для переноса на другое устройство используйте экспорт и импорт JSON.

## Локальный запуск

Статический сайт на HTML, CSS и JavaScript, без сборки. Для запуска нужны Python 3 и Node.js с npm.

```sh
npm start
```

Откройте [localhost:4173](http://127.0.0.1:4173). Проверки: `npm test`.

Папка `site/` автоматически публикуется на GitHub Pages при обновлении `main`.
