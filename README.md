# Внутри — карточки схема-терапии

Статический сервис для знакомства с карточками и подготовки к встрече с психологом. HTML, CSS и JavaScript, без сборки, API, аккаунтов, аналитики и внешних сетевых зависимостей. Модуль PDF и шрифты поставляются вместе с сайтом.

## Возможности

- Каталог с четырьмя типами, подгруппами, поиском и фильтром по личным отметкам.
- Иллюстрация занимает весь первый блок на телефоне и всю ширину левого блока на компьютере. 42 карточки переворачиваются по нажатию: на обороте полный оригинальный текст, который можно выделять и прокручивать. У режимов нет текстового оборота. Отдельная ссылка на фото и подпись под ним убраны; изображения не перерисованы. Пояснения с источниками и вопросы для наблюдения остаются рядом.
- Узнавание, отметки «Хочу обсудить» и «Мой ресурс», собственное имя режима и заметки.
- Профиль, тема встречи и связь карточек в одной ситуации.
- localStorage, резервная копия и импорт JSON, удаление профиля с подтверждением.
- «Мой профиль → PDF для психолога»: выбор карточек, иллюстраций, полных описаний, заметок и контекста встречи; загрузка одного PDF с русским текстом. Каждая карточка начинается с новой страницы, длинные записи продолжаются на следующих. Неотмеченные карточки и ссылки на них не попадают в документ.
- Проверка версии/содержимого импортируемого файла; повреждённые данные не перезаписываются автоматически. Конфликт между вкладками переводит текущую вкладку в режим без записи, с явным предупреждением.

Профиль не является стандартизированным тестом или диагнозом. Сервис не устанавливает причин, не рассчитывает выраженность схем и не предлагает самостоятельную работу с травматическими воспоминаниями.

## Упражнения

Во вкладке «Упражнения» есть три формата: дневник ситуации, три шага Здорового Взрослого и карточка поддержки. Карточки выбираются без изменения отметок профиля; записи сохраняются локально и входят в резервную копию JSON. Кнопка «PDF для психолога» доступна в основной навигации. Можно выбрать любые записи и карточки в один PDF или выгрузить одну запись из её формы. [Основания, источники и границы адаптации](EXERCISES.md).

Прямые ссылки: `#exercises` и `#profile`.

## Данные

122 предоставленные фотографии: 5 снимков инструкции и 117 снимков 75 разных карточек. Коллекция полная и совпадает с инструкцией: 10 потребностей, 18 ранних схем, 14 позитивных схем, 33 режима. Полные тексты 42 описаний перенесены в `site/card-text.js`. Режимы представлены одним иллюстрированным вариантом; оборот в оригинальной колоде содержит другой гендерный вариант.

`site/data.js` связывает стороны, названия, краткие пересказы и источники. Пояснения режимов основаны на литературе и явно отделены от текста оригинальной колоды. Вопросы — редакционная адаптация для самонаблюдения.

## Запуск и проверка

```sh
npm start
npm test
```

Локальный адрес: http://127.0.0.1:4173. Сборка не требуется. GitHub Actions проверяет модель профиля, каталог и состав PDF, затем публикует только папку `site` на GitHub Pages при push в `main`.

## Приватность

Заметки и записи упражнений находятся только в localStorage браузера под ключом `vnutri.profile.v1`. JSON/PDF формируется в браузере по запросу пользователя. PDF использует локальную копию pdfmake 0.2.23 и встроенные шрифты Roboto; лицензии и источник указаны в `site/vendor/pdfmake/README.md`. `connect-src 'none'` блокирует сетевые запросы из JS; все ресурсы локальные для сайта. Сам хостинг получает обычные HTTP-запросы файлов. Данные не зашифрованы; очистка хранилища браузера может их удалить. Профили с localhost и GitHub Pages не синхронизируются, нужен экспорт/импорт.

## Подготовка фотографий

Все 75 лицевых иллюстраций приведены к JPEG 900×1200. После выравнивания перспективы встроенный Imagegen удалил тени телефона и блики, выровнял освещение и бумажный фон. Пользователь одобрил образец такой обработки; это генеративная реставрация с возможными небольшими отличиями деталей от печатного оригинала. Содержание, композиция, подписи и авторские пометки сохранялись максимально близко к источнику. `site/originals` хранит веб-копии исходных снимков; пять фото инструкции не кадрировались. Исходники, координаты, журналы обработки и полные промпты находятся в локальной исключённой из репозитория папке `research`.
